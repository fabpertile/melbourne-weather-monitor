
MELBOURNE WEATHER MONITOR
=========================

This website is designed for the original iPad mini
running iOS 9.3.6.

INSTALLATION
------------

1. Publish this repository using GitHub Pages.
2. Open the published website in Safari on the iPad.
3. Tap the Share button.
4. Choose Add to Home Screen.
5. Name it Melbourne Weather.
6. Tap Add.

The dashboard uses Open-Meteo weather data.
An internet connection is required.

The dashboard refreshes hourly while it is open.

Historical and forecast values are model-derived.
They are not verified Bureau of Meteorology observations.
